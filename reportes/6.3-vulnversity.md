# 6.3 Hallazgos: Vulnversity

## H-05: Formulario de subida de archivos sin validación de tipo
- **Fase:** Explotación
- **Descripción:** el directorio `/internal/` expone un formulario de subida de archivos que acepta extensiones no validadas en el servidor web, lo que permite cargar archivos que el servidor puede interpretar y ejecutar.
- **Componente afectado:** Apache 2.4.41, directorio `/internal/` (puerto 3333)
- **Categoría (OWASP / CWE):** OWASP A04:2021 (Insecure Design); CWE-434
- **CVE:** No aplica
- **CVSS estimado:** Alto
- **Evidencia:** `bitacora/vulnversity_gobuster.txt`. Captura de la sala completada en `evidencias/post/general_vulnversity-completada.png`. Captura del formulario pendiente (Anexo B).
- **Herramienta utilizada:** Gobuster, curl, Burp Suite
- **Impacto CIA:** Confidencialidad, Integridad, Disponibilidad
- **Salvaguarda propuesta:** validar el tipo de archivo en el servidor (lista blanca de extensiones y de contenido), guardar las subidas fuera del directorio web y deshabilitar la ejecución de scripts en el directorio de subida.
- **Riesgo residual:** Bajo

## H-06: Binario con bit SUID en una ruta no estándar
- **Fase:** Post-explotación
- **Descripción:** el binario `/bin/systemctl` tiene activado el bit SUID, lo que permite que un usuario sin privilegios lo ejecute con permisos de root. Esta configuración no es la esperada para ese binario y amplía la superficie de escalada de privilegios.
- **Componente afectado:** `/bin/systemctl` (bit SUID activo)
- **Categoría (OWASP / CWE):** OWASP A05:2021 (Security Misconfiguration); CWE-250
- **CVE:** No aplica
- **CVSS estimado:** Alto
- **Evidencia:** salida del comando `find / -perm -4000 -type f 2>/dev/null`, pendiente de guardar en `bitacora/`. Captura pendiente (Anexo B).
- **Herramienta utilizada:** find
- **Impacto CIA:** Confidencialidad, Integridad, Disponibilidad
- **Salvaguarda propuesta:** quitar el bit SUID del binario (`chmod u-s`), auditar periódicamente los binarios con SUID y aplicar el principio de mínimo privilegio.
- **Riesgo residual:** Bajo
