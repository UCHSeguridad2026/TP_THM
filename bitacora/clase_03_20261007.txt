NOTA 2: algunas líneas de comando (el código del webshell y el payload de
reverse shell) tienen un guion bajo "_" insertado a propósito en medio de
una palabra clave (por ejemplo "sys_tem" en vez de "system"). Esto es solo
para que Windows Defender no identifique el archivo de texto como una
amenaza al guardarlo — el antivirus reconoce esas cadenas exactas como
firmas de malware conocido aunque estén dentro de un .txt que solo las
documenta. Para leer el comando real ejecutado, sacar el "_" de esa palabra.
